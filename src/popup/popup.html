        How saved states work
        
              
        A saved state keeps a reusable set of Cookies, Local Storage, and Session Storage for a site.
        
            
        

            
        
              
        Save the current state
        
              
          
                
        1. Open the site state you want to reuse, then select Save current state.
          2. 
                
        2. Choose the capture scope: the current data view, selected items, or all site data.
          3. 
                
        3. Add optional variables, then save. Saved states stay in this browser unless you export them.
          4. 
              
        
            
        

            
        
              
        Variables
        
              
        Enter one captured value per line. Matching values in the saved data are replaced with a variable.
        
              
        
                
        userId=42
        
                
        Prefills 42 when applying the saved state.
        
                
        !userId=42
        
                
        Asks for the value every time and does not store 42 in the saved state.
        
              
        
            
        

            
        
              
        Apply a saved state
        
              
          
                
        1. Select Apply and enter any requested variables.
          2. 
                
        2. For a different origin, explicitly enable origin mapping.
          3. 
                
        3. Preview the changes and conflict handling before applying them.
          4.
