Cookie Controller

Short description

View, edit, import, and export cookies, Local Storage, and Session Storage.

Detailed description

Manage website cookies, Local Storage, and Session Storage in one place. Cookie Controller helps developers, testers, and advanced users inspect and change site data from a popup or the Chrome side panel, without opening DevTools.
Source code: https://github.com/Atimynyc/cookies-manager

Main features

- Search cookies by name, value, domain, or path; create or delete entries, delete selected cookies, and set values in batches.
- Edit cookie values or expiration times while preserving domain, path, SameSite, Secure, and HttpOnly attributes.
- View, create, edit, and delete Local Storage and Session Storage entries for the selected website.
- Export the current view, selected items, or all site data as a versioned JSON package. Import with a difference preview, conflict strategies, and per-item results.
- Import and export cookies in Netscape/cURL cookie-jar format, including HttpOnly and session cookies.
- Quickly import cookies with separate Name and Value fields, or add a storage entry with key=value. Copy values, name=value pairs, or structured JSON.
- Save reusable site states locally with tags, origin rules, default conflict strategies, and variables supplied when applying a state. Rename, duplicate, export, apply, or delete saved states.
- Pin favorite cookies and storage entries to the top of their lists.
- Review recent changes, inspect before/after differences, retry failed operations, and undo supported changes during the current browser session.
- Switch between HTTP/HTTPS tabs in the current window and optionally reload the target page after changes.
- Use URL encoding/decoding, JSON formatting/compacting, and JWT payload decoding tools while editing values.
- Choose a light or dark theme for the popup and side panel.
- Use the interface in nine languages: English, Simplified Chinese, Traditional Chinese, Spanish, Brazilian Portuguese, German, French, Japanese, and Romanian.

Privacy

No ads, analytics, user tracking, or account required. Site data is processed on your device; the extension does not upload, sell, or share it with the developer or third-party servers. Preferences, site-access confirmations, favorite identifiers (without cookie or storage values), saved states, and history summaries remain in local extension storage. Saved states can contain the cookie and storage values you explicitly choose to save. Full before/after values and operation recovery data are retained only for the current browser session and are cleared when Chrome restarts or the extension reloads. Locally saved extension data can be removed by clearing the extension data or uninstalling the extension.

Usage notes

Open an HTTP/HTTPS page, open Cookie Controller, and approve access to the selected site when prompted. Choose Cookies, Local Storage, or Session Storage to begin. Website access is required to read and change that site's data and can be revoked in Chrome's extension settings. Operations you start may finish after you close the popup or side panel.

Netscape/cURL handles cookies only. Use JSON to preserve web storage and cookie metadata such as SameSite, Partitioned/CHIPS, and cookie store information.
The JWT tool only decodes the payload; it does not verify signatures or establish token validity.
Cookies and web storage may contain sign-in information or other sensitive values. Use trusted devices and protect copied or exported data.
