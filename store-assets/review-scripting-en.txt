Please review Cookie Controller v0.3.7 for Purple Potassium. This update replaces the generic API wrapper with a direct chrome.scripting.executeScript({...}) call in src/shared/storage-api.js. The scripting permission is required to read, create, edit and delete the selected website's Local Storage and Session Storage. chrome.storage only manages extension data and cannot provide this functionality.

To verify: open https://example.com, open Cookie Controller and approve site access, then choose Local or Session. Use Import > Quick entry to add a key/value, edit and save it, then delete it. Check that tab's DevTools > Application to confirm the changes.

Only bundled functions execute on the user-selected, authorized site. No remote code is downloaded or executed.
