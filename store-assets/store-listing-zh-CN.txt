Cookie Controller

简要说明

查看、编辑、导入和导出 Cookie、Local Storage 与 Session Storage。

详细说明

在一个界面中管理网站的 Cookie、Local Storage 与 Session Storage。Cookie Controller 面向开发者、测试人员和高级用户，可通过扩展弹出窗口或 Chrome 侧边栏查看和修改站点数据，无需打开开发者工具。
源代码：https://github.com/Atimynyc/cookies-manager

主要功能

- 按名称、值、域名或路径搜索 Cookie；支持新增、删除、批量删除和批量设置值。
- 修改 Cookie 的值或过期时间，同时保留域名、路径、SameSite、Secure 和 HttpOnly 等属性。
- 查看、添加、修改和删除所选网站的 Local Storage 与 Session Storage 数据。
- 将当前视图、选中项或全部站点数据导出为带版本号的 JSON 数据包；导入支持差异预览、冲突策略和逐项结果。
- 以 Netscape/cURL cookie jar 格式导入和导出 Cookie，兼容 HttpOnly 与会话 Cookie。
- 使用独立的 Name 与 Value 输入框快速导入 Cookie，或通过 key=value 添加存储项；支持一键复制值、name=value 或结构化 JSON。
- 在本地保存可复用的站点状态，支持标签、Origin 规则、默认冲突策略和应用时输入变量，以及重命名、复制、导出、应用和删除。
- 收藏常用 Cookie 和存储项，并在对应列表中置顶。
- 查看最近修改、对比修改前后差异、重试失败操作，并在当前浏览器会话中撤销符合条件的变更。
- 在当前窗口的 HTTP/HTTPS 标签页之间切换管理目标，并可设置修改后自动刷新页面。
- 编辑数据时可使用 URL 编码与解码、JSON 格式化与压缩、JWT Payload 解码工具。
- 弹出窗口与侧边栏均支持浅色和深色主题。
- 支持九种界面语言：英语、简体中文、繁体中文、西班牙语、巴西葡萄牙语、德语、法语、日语和罗马尼亚语。

隐私说明

无需注册账号，不含广告、统计分析或用户跟踪。站点数据仅在用户设备上处理，扩展不会将其上传、出售或共享给开发者或第三方服务器。界面偏好、站点访问确认、收藏标识（不含 Cookie 或存储值）、已保存状态及历史摘要保存在浏览器的扩展本地存储中。已保存状态可能包含用户主动选择保存的 Cookie 或网页存储值。用于差异查看、撤销和操作恢复的完整修改前后值仅保留在当前浏览器会话中，重启 Chrome 或重新加载扩展后清除。可通过清除扩展数据或卸载扩展删除本地保存的扩展数据。

使用说明

打开 HTTP/HTTPS 网页，再打开 Cookie Controller，按提示授权访问所选站点，即可切换 Cookie、Local Storage 和 Session Storage 进行管理。站点访问权限用于读取和修改该网站的数据，可随时在 Chrome 扩展设置中撤销。用户已启动的操作可能在关闭弹出窗口或侧边栏后继续完成。

Netscape/cURL 格式仅支持 Cookie；如需保留网页存储或 SameSite、Partitioned/CHIPS、Cookie store 等元数据，请使用 JSON 数据包。
JWT 工具仅解码 Payload，不验证签名，也不判断令牌是否可信或有效。
Cookie 和网页存储可能包含登录状态等敏感信息，请在可信设备上使用，并妥善保管复制或导出的数据。
