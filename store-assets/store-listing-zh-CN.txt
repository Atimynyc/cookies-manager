Cookie Controller

简短说明

查看、编辑、导入、导出和删除当前网页的 Cookie、Local Storage 与 Session Storage。

详细说明

Cookie Controller 是一款面向开发者、测试人员和高级用户的站点数据管理工具。它可以在弹出窗口或 Chrome 侧边栏中查看和管理当前网页的 Cookie、Local Storage 与 Session Storage，无需打开完整的开发者工具。

主要功能

- 查看当前网页的 Cookie，并按名称、值、域名或路径快速搜索。
- 修改单个 Cookie 的值，同时保留其域名、路径、过期时间、SameSite、Secure 和 HttpOnly 等属性。
- 新增、删除或批量删除 Cookie，并为多个选中项批量设置值。
- 查看、添加、修改和删除 Local Storage 与 Session Storage 数据。
- 收藏常用的 Cookie、Local Storage 和 Session Storage 项，并在对应列表中置顶显示。
- 在当前浏览器窗口的多个 HTTP/HTTPS 标签页之间快速切换管理目标。
- 将 Cookie、Local Storage 和 Session Storage 导出为版本化 JSON 数据包，并通过差异预览、冲突策略、逐项结果和整批撤销安全导入。
- 以常用的 Netscape/cURL cookie jar 格式导入和导出 Cookie，兼容 HttpOnly 与会话 Cookie 约定；SameSite、Partitioned/CHIPS 和 Cookie store 元数据仅由 JSON 数据包保留。
- 使用独立的 Name 与 Value 输入框快速导入一条或多条 Cookie；Storage 支持 key=value 单条导入。
- 一键复制 Cookie 值、name=value 键值对或结构化 JSON。
- 内置 URL 编码与解码、JSON 格式化与压缩、JWT Payload 解码工具。
- 保存可复用的站点状态，支持标签、Origin 规则、应用时变量，以及重命名、复制、导出、应用和删除。
- 查看最近的修改记录和修改前后差异，并在当前操作会话中撤销变更。
- 可选自动刷新页面，让修改后的站点状态立即生效。
- 同时支持扩展弹出窗口和 Chrome 侧边栏模式。

隐私说明

Cookie Controller 不包含广告、统计分析或用户跟踪功能，也不需要注册账号。插件读取的 Cookie 和网页存储数据只在用户设备上处理，不会上传、出售或共享给开发者或第三方服务器。界面偏好、收藏的站点数据标识（不包含 Cookie 或存储值）、用户主动保存的站点状态及最近修改记录保存在浏览器本地存储中，可通过清除扩展数据或卸载插件删除。

使用说明

插件仅在用户主动打开并操作时访问所选网站的数据。由于 Cookie 和网页存储可能包含登录状态等敏感信息，请只在可信设备上使用，导出数据后也请妥善保管。

JWT 工具仅解码 Payload 以便查看内容，不验证签名，也不判断令牌是否可信或有效。撤销所需的完整值快照仅保留在当前弹出窗口或侧边栏会话中。
