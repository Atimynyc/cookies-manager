# ![](../../assets/icon-48.png) Cookie Controller

ポップアップまたはChromeサイドパネルから、選択したウェブサイトのクッキー、Local Storage、およびSession Storageを管理できます。DevToolsを開かずにサイトデータを検査・変更したい開発者、テスター、および上級ユーザー向けに設計されています。

## はじめに

1. Chrome ウェブストアから [Cookie Controller](https://chromewebstore.google.com/detail/cookie-controller/hmfnocennjjcieebhojphobilohcdfda) をインストールしてください。
2. HTTP/HTTPSのページを開き、拡張機能のアイコンをクリックしてください。
3. プロンプトが表示されたら、選択したウェブサイトへのアクセスを許可し、次に「Cookie」、「Local Storage」、または「Session Storage」を選択してください。
4. データの検索、編集、インポート、エクスポートを行います。サイドパネルを開いて作業スペースを広げたり、変更後のページの自動再読み込みを有効にしたりできます。

ローカルにインストールするには、このリポジトリをクローンし、`chrome://extensions`を開いて開発者モードを有効にし、「Load unpacked」を使用して`manifest.json`を含むリポジトリフォルダを選択してください。この拡張機能は、同梱されているファイルから直接実行されるため、ビルド作業は必要ありません。

## 特長

- 名前、値、ドメイン、またはパスでクッキーを検索します。
- エディタでは、各クッキーの値や有効期限を変更する際、そのドメイン、パス、および「SameSite」、「Secure」、「HttpOnly」という属性が保持されます。
- Cookieの作成や削除、選択した項目の削除、および値の一括設定を行います。
- Local Storage および Session Storage のエントリを表示、作成、編集、削除します。
- お気に入りのHTTPクッキーやWebストレージのエントリは、各データリストの上部に表示されます。
- エクスポート内容をプレビューし、現在のビュー、選択した項目、またはサイト全体のデータを、バージョン管理された「JSON」パッケージとして、ファイルまたはクリップボードに保存します。差分プレビュー、項目ごとの選択、競合処理、進行状況、結果、および一括元に戻す機能を利用してインポートを行います。
- Netscape/cURL クッキー・ジャー形式でクッキーをインポートおよびエクスポートします。これには、`#HttpOnly_` の規約およびセッションクッキーが含まれます。
- タグ、オリジンルール、デフォルトの競合処理戦略、および状態を適用する際に入力した変数とともに、再利用可能なサイトの状態をローカルに保存します。保存された状態の名前変更、複製、エクスポート、適用、削除を行うことができます。
- Name および Value フィールドを個別に使用してクッキーを素早くインポートするか、`key=value` を使用してストレージエントリを追加します。値、`name=value` のペア、または構造化された JSON をコピーします。
- 値を編集する際は、URLエンコード／デコード、JSONのフォーマット／圧縮、およびJWTのペイロードデコードツールを使用してください。
- 現在のブラウザセッション中に、最近の変更内容や変更前後の違いを確認したり、失敗した操作を再実行したり、対応している変更を元に戻したりできます。
- 現在のブラウザウィンドウで、HTTP/HTTPSタブ間の対象を切り替えます。

Netscape/cURL 形式は、クッキーのみを扱います。SameSite 属性、Partitioned/CHIPS パーティション情報、および Chrome クッキーストア識別子は保持されません。これらの属性や Web ストレージを保持するには、JSON パッケージを使用してください。

## 言語とテーマ

このインターフェースは、英語、簡体字中国語、繁体字中国語、スペイン語、ブラジルポルトガル語、ドイツ語、フランス語、日本語、ルーマニア語に対応しています。すべての翻訳は拡張機能に同梱されており、オフラインでも利用可能です。

初回利用時には、Chromeの言語から対応言語が選択され、保存されます。対応する言語がない場合は、英語がデフォルトとして使用されます。`ro-RO`や`ro-MD`などのルーマニア語ロケールでは、ルーマニア語が選択されます。設定ボタンを使用して、いつでも言語を変更できます。言語を切り替えても、エディタの下書きは保持されます。

「太陽／月」ボタンを使用して、ライトテーマとダークテーマを切り替えることができます。通常モードではデフォルトでライトテーマが、シークレットモードではデフォルトでダークテーマが設定されます。各モードの設定はオペレーティングシステムとは独立して記憶され、同じモードで開かれている拡張機能のウィンドウ間で設定が同期されます。

## プライバシーとデータ管理

広告、分析、ユーザー追跡は一切なく、アカウントの登録も不要です。サイトのデータはユーザーの端末上で処理され、開発者やサードパーティのサーバーへアップロード、販売、共有されることはありません。デフォルトではサイトごとにアクセス許可を求めます。この権限はChromeの拡張機能設定から取り消すことができます。開始した操作は、ポップアップやサイドパネルを閉じた後に完了する場合があります。

設定またはサイトへのアクセス許可ダイアログで**すべてのサイトを許可**をオンにすると、アクセスするすべてのHTTP/HTTPSサイトのCookie、localStorage、sessionStorageへのアクセス許可を求めます。Chromeで承認すると、新しいサイトでの個別の確認は不要になります。スイッチをオフにすると、サイトごとの許可に戻ります。

設定、サイトへのアクセス確認、お気に入り識別子（項目の値を除く）、保存された状態、および履歴の概要は、ローカルの拡張機能ストレージに残ります。保存された状態には、ユーザーが明示的に保存を選択した Cookie やストレージの値を含めることができます。完全な「前」と「後」の値、および操作の復元データは、現在のブラウザセッション中のみ保持されます。Chromeを再起動するか、拡張機能を再読み込みすると、これらのデータは消去されます。ローカルに保存された拡張機能データを削除するには、拡張機能データを消去するか、拡張機能をアンインストールしてください。

Cookie や Web ストレージには、ログイン情報やその他の機密情報が含まれている場合があります。コピーやエクスポートされたデータを保護してください。JWT ツールは、確認目的のみとして Base64URL デコードされたペイロードを表示します。このツールは、署名の検証や、認証トークンの信頼性・有効性の確認は行いません。詳細については、[プライバシーポリシー](../../docs/privacy-policy.html) をご覧ください。

## ソフトウェア開発

開発に必要な依存関係をインストールし、リポジトリのルートディレクトリからチェックを実行します：

```sh
npm install
npm run lint
npm test
npm run test:locales
npm run test:acceptance -- --storage-only
```

最後のコマンドは、Chromium 内のウェブサイトの Local Storage および Session Storage データの読み取りと変更をテストするものです。ブラウザテストコマンドの全一覧、出力先、および動作の信頼性に関する詳細については、[開発およびリリースリファレンス（英語）](../../docs/development.md) をご覧ください。
