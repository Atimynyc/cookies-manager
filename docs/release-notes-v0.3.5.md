# v0.3.5 发布准备

本版本用于 Chrome Web Store 发布，包含 v0.3.3 已完成的操作可靠性能力、九种语言的界面和商店文案，以及隐私说明和发布素材。

## 发布核对

- Manifest 版本统一为 `0.3.5`。
- 发布包仅包含运行所需的 `manifest.json`、`assets/`、`src/` 和 `_locales/`。
- 新增右上角设置菜单，语言列表包含英语、简体中文、繁体中文、西班牙语、巴西葡萄牙语、德语、法语、日语和罗马尼亚语；首次安装按 Chrome 语言自动选中并保存，未匹配时默认英语。后续保留用户选择，旧版自动偏好会迁移为具体语言。罗马尼亚语支持 `ro`、`ro-RO`、`ro-MD` 自动匹配，可在设置中选择 Română，并提供 `store-assets/store-listing-ro.txt` 商店文案。
- 设置中用太阳/月亮按钮切换皮肤：太阳对应白色，月亮对应黑色。普通模式默认白色、隐私模式默认黑色，分别记住各自的选择，不跟随系统外观。偏好本地保存并同步到同模式下已打开的弹窗/侧边栏。语言切换即时生效且保留编辑草稿。
- 设置弹层保留 Settings 主标题，移除语言和配色方案的可见子标题，让语言下拉框和日月按钮在同一行显示，间距为 12px。控件高度统一，使用紧凑间距。
- 每份词库包含 562 条文案；新增语言通过 DeepL MCP 翻译，并校验技术术语、动态参数和商店字数限制。
- HTTP/HTTPS 站点访问使用可选主机权限，用户确认读取当前站点数据后才申请对应站点的权限；确认前不读取 Cookie 或网页存储。
- 商店说明与当前功能保持一致，移除已下线模板功能的描述。
- 新增 4 张 1280×800 功能宣传图，分别展示站点数据总览、批量导入、历史撤销和侧边栏工作区。
- 发布包：`release/cookie-controller-0.3.5.zip`（311,926 bytes，68 个文件，SHA-256：`476296DD2099847C356DCF7029964A1E1C436B14172B44DDF13532FC8349BD9B`）。已逐项确认包内文件与当前源码一致，包含可选站点权限、设置主标题、同排语言/主题控件、日月切换按钮、两种浏览模式的独立皮肤偏好和完整的九种语言词库。校验文件为 `release/cookie-controller-0.3.5.zip.sha256`。

## 本地化验证

- 192 项单元测试、JavaScript lint、文案来源覆盖、词库键和占位符一致性检查通过。
- 站点读取确认专项验收覆盖确认前零读取、取消、重试、拒绝授权、确认记录持久化，以及 380px 中文侧边栏的浅深色布局；报告截图位于 `output/playwright/site-access/`。自动化验收使用预授权主机权限的临时副本，覆盖扩展内的确认流程，未验证浏览器原生可选权限提示。
- 浏览器实测九种支持语言及意大利语的英语回退；验证原始 Cookie/Storage 数据保留、Cookie 编辑和快速导入、JSON/Netscape 导出、Storage 视图、380px 侧边栏及帮助代码示例。列表工具栏支持长译文换行，并逐项检查按钮未被裁切。
- 设置实测覆盖九种语言即时切换、编辑草稿保留、语言与皮肤持久化、跨界面同步、太阳/月亮图标、键盘操作，以及切换后的列宽调整和历史详情翻译。
- 原八种语言的设置布局已验证浅深色和 760/380/320px 宽度共 48 种组合，检查弹层边界、控件对齐、高度及语言名称完整显示；报告和截图位于 `output/playwright/settings-layout/`。罗马尼亚语另纳入语言切换和 380px 侧边栏验收。
- 主题专项实测普通模式默认白色、隐私模式默认黑色、两种模式独立记忆、同模式跨窗口同步、系统外观不影响默认值、保存失败后恢复；真实隐私窗口的原生 action 弹窗切换为白色后，关闭重开仍保留白色。报告与截图位于 `output/playwright/themes/`。
- 完整扩展验收、v0.3.2 隔离/草稿/容量回归和 v0.3.3 操作恢复/重试/撤销回归通过。v0.3.3 同时验证了原生 action popup 提交、关闭及重新打开。
- 多语言检查报告及截图：`output/playwright/locales/`。维护流程见 [localization.md](localization.md)。

## 已知边界

- Cookie、Local Storage 和 Session Storage 数据只在本地处理；导出的文件仍可能包含敏感值，请妥善保管。
- JWT 工具只解码 Payload，不验证签名。
- 批次撤销所需的完整值快照只保留在当前浏览器会话。
