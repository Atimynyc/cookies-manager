# v0.3.5 发布准备

本版本用于 Chrome Web Store 发布，包含 v0.3.3 已完成的操作可靠性能力和当前商店文案、隐私说明及发布素材的统一整理。

## 发布核对

- Manifest 版本统一为 `0.3.5`。
- 发布包仅包含运行所需的 `manifest.json`、`assets/` 和 `src/`。
- 商店说明与当前功能保持一致，移除已下线模板功能的描述。
- 新增 4 张 1280×800 功能宣传图，分别展示站点数据总览、批量导入、历史撤销和侧边栏工作区。
- 发布包：`release/cookie-controller-0.3.5.zip`（111,814 bytes，56 个文件，SHA-256：`CCFA95C732541B992550B91ED088A3023445C477BE35B5976DF9603BEB8561AB`）。

## 已知边界

- Cookie、Local Storage 和 Session Storage 数据只在本地处理；导出的文件仍可能包含敏感值，请妥善保管。
- JWT 工具只解码 Payload，不验证签名。
- 批次撤销所需的完整值快照只保留在当前浏览器会话。
